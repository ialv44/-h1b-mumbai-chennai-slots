# India H-1B Slot Dashboard (Mumbai & Chennai)

Static dashboard of **crowdsourced / third-party** public reports for US H-1B **biometrics (VAC)** and **interview** slots in **Mumbai** and **Chennai**.

**Not official.** This is not US Mission India or CGI data. Availability changes quickly. **Book appointments only on [usvisascheduling.com](https://www.usvisascheduling.com/).**

**Live site:** [https://ialv44.github.io/-h1b-mumbai-chennai-slots/](https://ialv44.github.io/-h1b-mumbai-chennai-slots/)

## Layout

GitHub Pages serves this repository from `/` on `main`.

| Path | Purpose |
|------|---------|
| `index.html` | Single-file dashboard (data embedded) |
| `latest.json` | Same snapshot as JSON |

## Refresh

`index.html` and `latest.json` are updated by **scheduled pushes** to `main`. This project does not scrape [usvisascheduling.com](https://www.usvisascheduling.com/).
